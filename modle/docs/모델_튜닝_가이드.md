# 모델 튜닝 가이드

하이퍼파라미터를 직접 바꿀 때는 아래 파일 하나를 열면 됩니다.

```text
backend/model_tuning_settings.py
```

## 1. 주로 바꿀 값

### 1단계 혼잡일 분류 모델

`CLASSIFIER_PARAMS`를 수정합니다.

```python
CLASSIFIER_PARAMS = {
    "depth": 6,
    "learning_rate": 0.06,
    "iterations": 800,
    "l2_leaf_reg": 5.0,
}
```

현재 기본값은 혼잡일 랭킹 지표(`NDCG@20`)를 우선해서 선택한 값입니다.

### 2단계 방문객 수 예측 모델

`REGRESSOR_PARAMS`를 수정합니다.

```python
REGRESSOR_PARAMS = {
    "depth": 10,
    "learning_rate": 0.04,
    "iterations": 1200,
    "l2_leaf_reg": 8.0,
}
```

현재 기본값은 1단계 혼잡일 분류 모델을 고정한 뒤, 2단계 방문객 수 예측 모델을 100회 무작위 탐색해 `NDCG@20`이 가장 높은 조합으로 선택한 값입니다.

### 혼잡일 기준과 가중치

```python
BUSY_LABEL_RATIO = 0.15
TOP_10_WEIGHT = 4.0
TOP_20_WEIGHT = 2.0
```

## 2. 값의 의미

| 이름 | 의미 | 바꾸면 생기는 일 |
| --- | --- | --- |
| `depth` | 트리 깊이 | 높이면 복잡한 패턴을 더 잡지만 과적합 위험이 커집니다. |
| `learning_rate` | 학습 속도 | 낮추면 안정적이고, 보통 `iterations`를 함께 늘립니다. |
| `iterations` | 트리 개수 | 늘리면 학습 시간이 길어지고 성능이 좋아질 수도 있습니다. |
| `l2_leaf_reg` | 규제 강도 | 높이면 과적합을 줄이는 방향으로 갑니다. |
| `BUSY_LABEL_RATIO` | 상위 몇 %를 혼잡일로 볼지 | 낮추면 더 극단적으로 붐비는 날만 혼잡일로 봅니다. |
| `TOP_10_WEIGHT` | 상위 10% 방문일 가중치 | 높이면 피크 날짜를 더 중요하게 학습합니다. |
| `TOP_20_WEIGHT` | 상위 20% 방문일 가중치 | 높이면 붐비는 날짜 전반을 더 중요하게 학습합니다. |

## 3. 수정 후 적용 방법

하이퍼파라미터를 바꾼 뒤에는 기존 예측 캐시를 지워야 합니다.

삭제할 파일:

```text
backend/data/artifacts/portable_predictions.csv
backend/data/artifacts/portable_predictions_metadata.json
```

그 다음 아래 명령을 실행합니다.

```bat
py scripts\prepare_artifacts.py
```

서버를 다시 켜면 새 설정으로 만든 예측 결과가 사용됩니다.

## 4. 추천 튜닝 순서

한 번에 하나만 바꾸는 것을 추천합니다.

```text
1. depth 변경
2. 캐시 삭제
3. py scripts\prepare_artifacts.py 실행
4. 성능지표 확인
5. 결과 기록
6. 다음 값 변경
```

여러 값을 한 번에 바꾸면 어떤 값 때문에 성능이 좋아졌거나 나빠졌는지 알기 어렵습니다.
